# 寶石鑑定室～西拉雅國家風景區官田遊客中心

國小特教戶外教學用的觸控互動遊戲，搭配西拉雅國家風景區官田遊客中心的建築、常設展與公共藝術。適用觸控大電視、平板與電腦，畫面會自動配合螢幕大小，不需要捲動。

- **線上玩**：https://marypingu213-code.github.io/siraya-nsa-trip/
- **離線版**：[download/寶石鑑定室_官田遊客中心.html](download/寶石鑑定室_官田遊客中心.html)（約 9 MB，圖片全部包在檔案裡，下載後雙擊用 Chrome 或 Edge 開啟，不需要網路）

## 七個遊戲

| 遊戲 | 內容 |
| --- | --- |
| 三大主軸配對 | 把常設展展板上的 24 個景點，放進「水圳之源、湖丘時光、雲水之間」 |
| 聽線索猜景點 | 聽一句線索，從展板圖片中找出景點，可加猜所屬路線 |
| 建築師的祕密 | 看遊客中心的實景照片，配對建築設計和它的用意 |
| Tabe! Tabe! 仙境西拉雅 | 草坡上五隻黑白動物雕塑：認動物、代表風土山水人情味 |
| 套色印章明信片 | 依序蓋三色印章疊出明信片，再加蓋官田遊客中心紀念章 |
| 湖丘之物：認識植物 | 館內植物標本展示櫃的 12 種植物，看標本或聽特徵認植物 |
| 實景找一找 | 在遊客中心照片上點出大屋頂、壺、天窗等設計；老師也可上傳自己的照片 |

每個遊戲都有語音朗讀、答錯提示，完成全部遊戲可得到「寶石鑑定加」證書。

## 檔案說明

| 路徑 | 用途 |
| --- | --- |
| `src/game.html` | 遊戲原始碼，修改都從這裡改 |
| `img/` | 遊戲用的照片與插圖 |
| `build.py` | 由 `src/game.html` 產生 `index.html`（網站）和 `download/` 裡的離線版 |
| `tools/draw_plants.py` | 產生植物插圖（油桐種子等）的程式 |

修改 `src/game.html` 或 `img/` 之後，執行一次：

```
python3 build.py
```

再把變更推送到 `main`，GitHub Pages 會在一兩分鐘內自動更新網站。

## 第一次開啟網站

到 GitHub 專案的 **Settings → Pages**，在 **Build and deployment** 選 **Deploy from a branch**，分支選 `main`、資料夾選 `/ (root)`，按 **Save**。約一兩分鐘後，網站會出現在上方的「線上玩」網址。
